# QAMC Documentation Governance

Current documentation structure is defined in `docs/README.md`.

Principles:
- one live state file (`docs/STATE.md`);
- one concise roadmap (`docs/ROADMAP.md`);
- one active decision set (`docs/decisions/ACTIVE.md`);
- detailed architecture loaded on demand;
- historical evidence is preserved but not treated as current instruction;
- Claude Code workflow mechanics live in native `.claude/` primitives rather than governance prose.
