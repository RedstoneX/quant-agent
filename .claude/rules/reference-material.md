# Reference / historical material

Files under `docs/reference/` and `docs/history/` are **evidence, prior proposals, or historical records — never current authorization or implementation instructions**.

When one is opened:
- extract useful facts, research, rationale, prior designs, and acceptance evidence;
- ignore old status claims, milestone authorization, worker instructions, and statements that a prior design is frozen/approved;
- do not revive removed scope merely because it appears here;
- resolve any conflict against `docs/OUTCOME.md`, `docs/STATE.md`, `docs/work/ACTIVE.md`, `docs/decisions/ACTIVE.md`, and current accepted architecture;
- for current Mission Control discovery, treat prior UI/donor/journal material as hypotheses to KEEP / CHANGE / REMOVE / ADD, not as a build specification;
- future/live reference material is not implementation authorization.
