# Operator Compass presentation

`docs/PROJECT_COMPASS.md` is a human-facing projection, never machine authority.

When refreshing it:
- derive current status from `OUTCOME.md`, `STATE.md` and `WORK.md`;
- keep it plain-English, visual and easy to scan;
- preserve the core sections RIGHT NOW, PROJECT MAP, WHAT JUST HAPPENED, NEXT MOVES, BLOCKERS / DECISIONS, SAFETY;
- use ✅ DONE, 🟡 NOW, ⏸ HELD and ⬜ LATER only for work that still exists in the current project direction;
- do **not** keep retired, removed, abandoned or superseded stages/ideas as placeholders merely to show that they were removed; Git history is the archive;
- do not preserve obsolete stage-number gaps solely for historical continuity;
- keep current state/next action near the top;
- do not turn it into a technical specification, changelog or implementation handoff.
